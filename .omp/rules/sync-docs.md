# Rule: Sync OMP Telegram Bot Documentation

When developing, adding features, or changing commands in this repository:
1. ALWAYS update `README.md` to reflect user-facing commands, capabilities, or setup.
2. ALWAYS update `AGENTS.md` with any changes to the agent flow, state model, or command interface.
3. ALWAYS update `PRD.md` with new specifications, requirements, or invariants.
4. Keep all three synchronized with `RULES.md`.
